# Lash Designer 5.10.1 — Mobile App Foundation · Parte 2

## Escopo

Segunda etapa da migração do painel mobile para um padrão de aplicação móvel familiar, preservando o desktop.

### Clientes
- tabela desktop preservada;
- lista mobile própria com avatar, contato, consentimento promocional, última visita e total gasto;
- busca local por nome, telefone ou e-mail;
- empty state específico para busca sem resultado;
- touch targets e hierarquia adequados para 390–430 px.

### Serviços
- catálogo mobile próprio com imagem, duração e preço;
- CTA de novo serviço mais compacto e explícito;
- edição continua na mesma lógica funcional;
- editor vira bottom sheet no celular;
- tabela desktop permanece intacta.

### WhatsApp
- inbox e conversa permanecem mutuamente exclusivas no celular;
- tabs ganham leitura de app móvel;
- lista de conversas recebe densidade/touch targets maiores;
- conversa recebe header compacto, voltar, Luma como ação de ícone e composer mobile;
- nova conversa vira bottom sheet;
- Automações, Campanhas e Conexão mantêm a lógica atual com cartões adaptados.

- Configurações, Indicações, Setup/Onboarding e Booking público: Parte 4.
